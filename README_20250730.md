# TauDEM Installation and Testing on Remote Server

This README documents the process of installing [TauDEM](https://github.com/dtarb/TauDEM) and running its test suite on a remote Linux server.

---

## 1. Clone the TauDEM Repository

Clone the TauDEM GitHub repository into your `tools/src/` directory:

```bash
git clone https://github.com/dtarb/TauDEM.git ~/tools/src/TauDEM
```

## 2. Build TauDEM

After cloning, follow the installation instructions from the repository. On our system, some adjustments were needed:

🔧 Update to Support Current OpenMPI
Modify the `linklib.h` file to reflect the updated OpenMPI version available on the server. This may involve changing linker flags or library references.

🛠️ Compile the Tools
Once the `linklib.h` file has been updated, compile TauDEM using:

```bash
make
```

This will build the tools and place the binaries into `~/tools/src/TauDEM/bin/`.

## 3. Download TauDEM Test Data
Clone the test data repository into your `tools/tests/` directory:

```bash
git clone https://github.com/dtarb/TauDEM-Test-Data.git ~/tools/tests/TauDEM-Test-Data
```

## 4. Run the Tests
Use the .sh scripts provided in the test data repository (instead of the .bat files, which are for Windows).

🔧 Before Running the Tests:
Update each test script to point to your local TauDEM executables:

```bash
/usr_dir/tools/src/TauDEM/bin/ # define your directory
```

Update the path to the `bats` testing framework if necessary.

Make sure the `.sh` test files are executable:

```bash
chmod +x taudem-tests.sh
```

▶️ Run the Tests
Run the main script with:

```bash
./taudem-tests.sh
```

## 5. Troubleshooting and Fixes
Several modifications were required to get the tests working:

Some scripts referenced incorrect or outdated file names and paths.

Input files were missing for a few test cases, so those specific tests were skipped or modified.

Typos and hardcoded paths were manually corrected in the .sh test scripts.

## ✅ Summary
TauDEM was cloned and compiled successfully.

The `linklib.h` file was updated to reflect current OpenMPI configurations.

Tests were run using the Linux `.sh` scripts with path modifications.

Most tests passed after minor fixes, and core TauDEM functionality is verified to be working.

This setup should be reproducible for other users on this server by following the steps above.
